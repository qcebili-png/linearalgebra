1. Systems and row reduction

Lay §1.1–1.2 · Week 1

In plain wordsA linear system asks where lines (or planes) meet. There are only three outcomes: no solution, exactly one, or infinitely many. Write the system as an augmented matrix and clean it with row operations. They never change the solution set.
Definitions The three row operations: replace a row by itself plus a multiple of another, swap two rows, scale a row by a nonzero number. A matrix is in echelon form if all zero rows are at the bottom, each leading entry is to the right of the one above, and entries below a leading entry are 0. It is reduced (RREF) if also every leading entry is 1 and is the only nonzero entry in its column. A pivot is a leading entry; a pivot column holds one. Variables of pivot columns are basic, the others free.
Existence and uniqueness theoremA system is consistent iff the echelon form has no row \([0\ \cdots\ 0\ |\ b]\) with \(b\neq0\). If it is consistent, the solution is unique iff there are no free variables.
Recipe: row reduction 1. Take the leftmost nonzero column: this is a pivot column. Swap so the top entry is nonzero. 2. Use replacements to make all entries below that pivot 0. 3. Ignore that row and repeat on what is left. Now you have echelon form. 4. For RREF: from the rightmost pivot upward, scale the pivot to 1 and clear above it. 5. Read off: basic variables in terms of the free ones.
Watch out A row \([0\ 0\ 0\ |\ 5]\) means no solution, while \([0\ 0\ 0\ |\ 0]\) is harmless. Free variables come from columns of the coefficient part only, never from the \(|\) column. Do arithmetic one operation at a time, and write each operation next to its row.

Worked example

Solve \(x_1-2x_2+x_3=0,\ \ 2x_2-8x_3=8,\ \ -4x_1+5x_2+9x_3=-9\).

\[\left[\begin{array}{ccc|c}1&-2&1&0\\0&2&-8&8\\-4&5&9&-9\end{array}\right]\xrightarrow{R_3+4R_1}\left[\begin{array}{ccc|c}1&-2&1&0\\0&2&-8&8\\0&-3&13&-9\end{array}\right]\xrightarrow{\frac12R_2,\ R_3+3R_2}\left[\begin{array}{ccc|c}1&-2&1&0\\0&1&-4&4\\0&0&1&3\end{array}\right]\]

Back-substitute: \(x_3=3\), \(x_2=4+4\cdot3=16\), \(x_1=2\cdot16-3=29\). Unique solution \((29,16,3)\): three pivots, no free variable.

2. Vectors, span and Ax = b

Lay §1.3–1.4 · Week 2

In plain wordsA vector is a list of numbers (an arrow in \(\mathbb R^n\)). A linear combination mixes vectors with weights. The span is everything you can reach that way. The matrix equation \(A\mathbf x=\mathbf b\) is the same question in disguise: is \(\mathbf b\) a combination of the columns of \(A\), and with which weights?
Definitions \(\mathbf y=c_1\mathbf v_1+\cdots+c_p\mathbf v_p\) is a linear combination. \(\operatorname{Span}\{\mathbf v_1,\dots,\mathbf v_p\}\) is the set of all of them. For \(A=[\mathbf a_1\ \cdots\ \mathbf a_n]\) (\(m\times n\)) and \(\mathbf x\in\mathbb R^n\): \(A\mathbf x=x_1\mathbf a_1+\cdots+x_n\mathbf a_n\).
Theorem (§1.4)For an \(m\times n\) matrix \(A\) these are equivalent: (a) \(A\mathbf x=\mathbf b\) has a solution for every \(\mathbf b\) in \(\mathbb R^m\); (b) every \(\mathbf b\) is a combination of the columns; (c) the columns span \(\mathbb R^m\); (d) \(A\) has a pivot in every row.
Recipe: is b in Span{a₁,…,aₙ}? 1. Form the augmented matrix \([\mathbf a_1\ \cdots\ \mathbf a_n\ |\ \mathbf b]\). 2. Row reduce to echelon form. 3. Consistent means yes, and the solution is the list of weights. A row \([0\cdots0\,|\,b\neq0]\) means no.
Watch out \(A\mathbf x\) exists only if the number of columns of \(A\) equals the number of entries of \(\mathbf x\). The condition is a pivot in every row, not every column. \(\operatorname{Span}\{\mathbf v\}\) for \(\mathbf v\ne\mathbf 0\) is a line through the origin; \(\mathbf 0\) is always in a span.

Worked example

Is \(\mathbf b=(7,4,-3)\) in \(\operatorname{Span}\{\mathbf a_1,\mathbf a_2\}\), with \(\mathbf a_1=(1,-2,-5)\), \(\mathbf a_2=(2,5,6)\)? Row reduce \(\left[\begin{smallmatrix}1&2&7\\-2&5&4\\-5&6&-3\end{smallmatrix}\right]\to\left[\begin{smallmatrix}1&2&7\\0&1&2\\0&0&0\end{smallmatrix}\right]\). Consistent, with \(x_2=2\), \(x_1=3\). So \(\mathbf b=3\mathbf a_1+2\mathbf a_2\): yes.

3. Solution sets and linear independence

Lay §1.5, 1.7 · Week 3

In plain wordsThe equation \(A\mathbf x=\mathbf 0\) (homogeneous) always has the trivial solution \(\mathbf x=\mathbf 0\). The interesting question is whether it has more. That is exactly the question of linear independence: can the columns cancel each other out? And the solutions of \(A\mathbf x=\mathbf b\) are one particular solution plus the solutions of \(A\mathbf x=\mathbf 0\).
Definitions \(A\mathbf x=\mathbf 0\) has a nontrivial solution iff it has a free variable. Vectors \(\mathbf v_1,\dots,\mathbf v_p\) are linearly independent if \(x_1\mathbf v_1+\cdots+x_p\mathbf v_p=\mathbf 0\) only for \(x_1=\cdots=x_p=0\); otherwise dependent.
Theorems If \(A\mathbf x=\mathbf b\) is consistent with a particular solution \(\mathbf p\), its solution set is \(\{\mathbf p+\mathbf v_h:\ A\mathbf v_h=\mathbf 0\}\). The columns of \(A\) are independent iff \(A\mathbf x=\mathbf 0\) has only the trivial solution iff every column is a pivot column. Two vectors are dependent iff one is a multiple of the other. A set containing \(\mathbf 0\) is dependent. A set of \(p\) vectors in \(\mathbb R^n\) with \(p>n\) is dependent.
Recipe Parametric vector form: row reduce \([A\ |\ \mathbf 0]\) (or \([A\ |\ \mathbf b]\)), solve the basic variables, then write \(\mathbf x\) as (particular vector) + \(t_1\)(vector) + \(t_2\)(vector)…, one vector per free variable. Independence test: put the vectors as columns, row reduce, check for a pivot in every column.
Watch out Independence needs a pivot in every column; spanning needs a pivot in every row. Do not mix them up. Two vectors can be independent even if no entry looks proportional. Check all entries.

Worked examples

Solve \(3x_1+5x_2-4x_3=0\). Only \(x_1\) is basic: \(x_1=-\tfrac53x_2+\tfrac43x_3\), so \(\mathbf x=x_2\left(-\tfrac53,1,0\right)+x_3\left(\tfrac43,0,1\right)\). Two free variables, so the solution set is a plane through the origin.

Are \(\mathbf v_1=(1,2,3)\), \(\mathbf v_2=(4,5,6)\), \(\mathbf v_3=(2,1,0)\) independent? \(\left[\begin{smallmatrix}1&4&2\\2&5&1\\3&6&0\end{smallmatrix}\right]\to\left[\begin{smallmatrix}1&4&2\\0&-3&-3\\0&0&0\end{smallmatrix}\right]\). Column 3 has no pivot, so they are dependent: \(2\mathbf v_1-\mathbf v_2+\mathbf v_3=\mathbf 0\).

4. Linear transformations

Lay §1.8–1.9 · Week 4

In plain wordsA transformation \(T:\mathbb R^n\to\mathbb R^m\) is a rule that turns each input vector into an output vector. It is linear if it respects addition and scaling. Every linear transformation is just multiplication by a matrix, and you build that matrix by asking where the basis vectors \(\mathbf e_1,\dots,\mathbf e_n\) go.
Definitions \(T\) is linear if \(T(\mathbf u+\mathbf v)=T(\mathbf u)+T(\mathbf v)\) and \(T(c\mathbf u)=cT(\mathbf u)\). Then \(T(\mathbf 0)=\mathbf 0\). Standard matrix: \(A=[T(\mathbf e_1)\ \cdots\ T(\mathbf e_n)]\), and \(T(\mathbf x)=A\mathbf x\). \(T\) is onto \(\mathbb R^m\) if every \(\mathbf b\) is the image of at least one \(\mathbf x\); one-to-one if every \(\mathbf b\) is the image of at most one \(\mathbf x\).
Theorems \(T\) is one-to-one iff \(T(\mathbf x)=\mathbf 0\) has only the trivial solution iff the columns of \(A\) are independent (pivot in every column). \(T\) is onto iff the columns of \(A\) span \(\mathbb R^m\) (pivot in every row).
Recipe: standard matrix 1. Compute \(T(\mathbf e_1),\dots,T(\mathbf e_n)\) (the columns of the identity matrix as inputs). 2. Put them side by side as columns. Common ones in \(\mathbb R^2\): rotation by \(\theta\) is \(\left[\begin{smallmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{smallmatrix}\right]\); reflection in the \(x_1\)-axis is \(\left[\begin{smallmatrix}1&0\\0&-1\end{smallmatrix}\right]\); horizontal shear is \(\left[\begin{smallmatrix}1&k\\0&1\end{smallmatrix}\right]\); projection onto the \(x_1\)-axis is \(\left[\begin{smallmatrix}1&0\\0&0\end{smallmatrix}\right]\).
Watch out The columns are \(T(\mathbf e_j)\), not the rows. If \(A\) is \(m\times n\), the domain is \(\mathbb R^n\) and the codomain \(\mathbb R^m\). A map like \(\mathbf x\mapsto\mathbf x+\mathbf b\) with \(\mathbf b\ne\mathbf 0\) is not linear, because \(T(\mathbf 0)\ne\mathbf 0\).

Worked example

\(T\) rotates the plane counterclockwise by \(90^\circ\). Then \(T(\mathbf e_1)=(0,1)\) and \(T(\mathbf e_2)=(-1,0)\), so \(A=\left[\begin{smallmatrix}0&-1\\1&0\end{smallmatrix}\right]\) and \(T(2,3)=(-3,2)\).

5. Matrix algebra and inverses

Lay §2.1–2.3, 2.5 · Weeks 5–6

In plain wordsMatrices multiply by combining rows with columns, and the order matters. An inverse undoes a matrix, and it exists exactly when the matrix has a pivot in every row and column.
Key facts\(AB\) has columns \(A\mathbf b_j\); usually \(AB\ne BA\). \((AB)^T=B^TA^T\), \((AB)^{-1}=B^{-1}A^{-1}\). For \(A=[a,b;c,d]\) (rows separated by ;) with \(ad-bc\ne0\): \(A^{-1}=\frac1{ad-bc}[d,-b;-c,a]\). Invertible Matrix Theorem (\(n\times n\)): \(A\) invertible \(\iff\) \(n\) pivots \(\iff\) \(A\mathbf x=\mathbf 0\) only trivially \(\iff\) columns independent \(\iff\) columns span \(\mathbb R^n\) \(\iff\) \(A^T\) invertible. LU: \(A=LU\), \(U\) echelon, \(L\) unit lower triangular holding the multipliers.
RecipeInverse: row reduce \([A\ |\ I]\) to \([I\ |\ A^{-1}]\); if \(I\) does not appear, no inverse. Solve \(A\mathbf x=\mathbf b\) by \(\mathbf x=A^{-1}\mathbf b\). With LU: solve \(L\mathbf y=\mathbf b\) forward, then \(U\mathbf x=\mathbf y\) backward.
Watch outReverse the order in \((AB)^{-1}\) and \((AB)^T\). \(AB=AC\) does not give \(B=C\). Only square matrices have inverses.

Worked example

\(A=[2,1;6,5]\): \(R_2-3R_1\) gives \(U=[2,1;0,2]\) and \(L=[1,0;3,1]\). Check: \(LU=[2,1;6,3+2]=A\).

6. Subspaces, basis and rank

Lay §2.8–2.9 · Week 7

In plain wordsA subspace is a flat piece through the origin. Every matrix gives two: the column space (what \(A\mathbf x\) can reach) and the null space (what \(A\) sends to \(\mathbf 0\)). A basis is a minimal list that builds the subspace.
Key factsSubspace: contains \(\mathbf 0\), closed under addition and scalar multiples. \(\operatorname{Col}A\) = span of columns; \(\operatorname{Nul}A=\{\mathbf x:A\mathbf x=\mathbf 0\}\). Basis = independent spanning set; all bases of a subspace have the same size, the dimension. Rank theorem: \(\operatorname{rank}A+\dim\operatorname{Nul}A=n\) (number of columns). Coordinates: if \(\mathcal B=\{\mathbf b_1,\dots,\mathbf b_p\}\) and \(\mathbf x=c_1\mathbf b_1+\cdots+c_p\mathbf b_p\) then \([\mathbf x]_{\mathcal B}=(c_1,\dots,c_p)\).
RecipeBasis of \(\operatorname{Col}A\): the pivot columns of the original \(A\). Basis of \(\operatorname{Nul}A\): the vectors in the parametric vector form of \(A\mathbf x=\mathbf 0\). Coordinates: solve \([\mathbf b_1\ \cdots\ \mathbf b_p\ |\ \mathbf x]\).
Watch outTake pivot columns from \(A\), not from its echelon form. A set not containing \(\mathbf 0\) is not a subspace. \(\operatorname{rank}\) = number of pivots.

Worked example

\(A=[1,2,0,1;0,0,1,3]\): pivots in columns 1, 3, so \(\operatorname{Col}A\) has basis \((1,0),(0,1)\), rank 2. \(x_1=-2x_2-x_4,\ x_3=-3x_4\): basis of \(\operatorname{Nul}A\) is \((-2,1,0,0),(-1,0,-3,1)\). Check \(2+2=4\).

7. Determinants

Lay §3.1–3.3 · Week 8

In plain wordsThe determinant is one number that says whether a square matrix is invertible, and by what factor it scales area or volume.
Key facts\(\det[a,b;c,d]=ad-bc\). Expand along any row or column with signs \(+-+\,/\,-+-\). Triangular: product of the diagonal. Row operations: replacement changes nothing, a swap flips the sign, scaling a row by \(k\) multiplies \(\det\) by \(k\). \(\det(AB)=\det A\det B\), \(\det A^T=\det A\), \(\det A^{-1}=1/\det A\), \(\det(kA)=k^n\det A\). \(A\) invertible \(\iff\det A\ne0\). Cramer: \(x_i=\det A_i(\mathbf b)/\det A\), where column \(i\) is replaced by \(\mathbf b\). Area of the parallelogram spanned by the columns: \(|\det A|\).
RecipeExpand along the row or column with the most zeros, or row reduce to triangular and track swaps and scalings.
Watch out\(\det(kA)=k^n\det A\), not \(k\det A\). \(\det(A+B)\ne\det A+\det B\). Do not forget the checkerboard signs.

Worked example

\(\det[2,0,0;1,3,0;4,5,6]=2\cdot3\cdot6=36\) (triangular).

8. Vector spaces

Lay §4.1–4.7 · Weeks 9–11

In plain wordsEverything you did with vectors in \(\mathbb R^n\) also works for polynomials, matrices and functions, as long as they can be added and scaled. Then bases, dimension, rank and coordinates carry over.
Key factsA vector space is a set with addition and scalar multiplication obeying the usual rules (zero vector, negatives, closure, distributivity). Examples: \(\mathbb R^n\); \(\mathbb P_n\) (polynomials of degree \(\le n\), dimension \(n+1\)); \(\mathbb M_{m\times n}\) (dimension \(mn\)). For linear \(T\): \(\ker T=\{\mathbf x:T\mathbf x=\mathbf 0\}\), \(\operatorname{range}T\) = all outputs. Spanning Set Theorem: a spanning set can be shrunk to a basis. The coordinate map \(\mathbf x\mapsto[\mathbf x]_{\mathcal B}\) is linear and one-to-one. Change of basis: \([\mathbf x]_{\mathcal C}=P_{\mathcal C\leftarrow\mathcal B}[\mathbf x]_{\mathcal B}\), with columns \([\mathbf b_j]_{\mathcal C}\). In \(\mathbb R^n\): row reduce \([\mathcal C\ |\ \mathcal B]\to[I\ |\ P]\).
RecipeSubspace test: check \(\mathbf 0\), closure under \(+\), closure under scalars. Coordinates in \(\mathbb P_n\): match coefficients of \(1,t,t^2,\dots\).
Watch outA set defined by a condition like \(p(0)=1\) fails the zero test. \([\mathbf x]_{\mathcal B}\) depends on the order of the basis.

Worked example

In \(\mathbb P_2\) with basis \(\{1,t,t^2\}\): \(2+3t-t^2\) has coordinates \((2,3,-1)\).

9. Eigenvalues and diagonalization

Lay §5.1–5.3 · Week 12

In plain wordsAn eigenvector is a direction that \(A\) only stretches: \(A\mathbf v=\lambda\mathbf v\). If there are enough of them, \(A\) becomes a diagonal matrix in the right basis, which makes powers easy.
Key facts\(\lambda\) is an eigenvalue iff \(\det(A-\lambda I)=0\); its eigenspace is \(\operatorname{Nul}(A-\lambda I)\) and \(\mathbf v\ne\mathbf 0\). For triangular \(A\), the eigenvalues are the diagonal entries. Eigenvectors for different eigenvalues are independent. \(\operatorname{tr}A=\sum\lambda_i\), \(\det A=\prod\lambda_i\). \(A\) is diagonalizable iff it has \(n\) independent eigenvectors; then \(A=PDP^{-1}\), \(P\) = eigenvectors as columns, \(D\) = eigenvalues in the same order, and \(A^k=PD^kP^{-1}\).
Recipe1. Solve \(\det(A-\lambda I)=0\). 2. For each \(\lambda\) solve \((A-\lambda I)\mathbf x=\mathbf 0\). 3. If you get \(n\) independent vectors, build \(P\) and \(D\).
Watch out\(\mathbf v=\mathbf 0\) is never an eigenvector. Repeated eigenvalue does not guarantee diagonalizable: compare the eigenspace dimension with the multiplicity.

Worked example

\(A=[4,1;2,3]\): \(\lambda^2-7\lambda+10=0\Rightarrow\lambda=2,5\). \(\lambda=5\): \(\mathbf v=(1,1)\). \(\lambda=2\): \(\mathbf v=(1,-2)\). So \(P=[1,1;1,-2]\), \(D=\operatorname{diag}(5,2)\).

10. Orthogonality, Gram–Schmidt and least squares

Lay §6.1–6.7 · Weeks 13–15

In plain wordsThe dot product brings lengths and angles. Perpendicular pieces can be handled one at a time, which gives projections, orthogonal bases, and the best approximate solution when \(A\mathbf x=\mathbf b\) has none.
Key facts\(\mathbf u\cdot\mathbf v\), \(\|\mathbf v\|=\sqrt{\mathbf v\cdot\mathbf v}\), distance \(\|\mathbf u-\mathbf v\|\); orthogonal iff \(\mathbf u\cdot\mathbf v=0\). \(W^\perp\) = vectors orthogonal to all of \(W\); \((\operatorname{Row}A)^\perp=\operatorname{Nul}A\). An orthogonal set of nonzero vectors is independent. \(\operatorname{proj}_{\mathbf u}\mathbf y=\frac{\mathbf y\cdot\mathbf u}{\mathbf u\cdot\mathbf u}\mathbf u\). Gram–Schmidt: \(\mathbf v_1=\mathbf x_1\), \(\mathbf v_2=\mathbf x_2-\frac{\mathbf x_2\cdot\mathbf v_1}{\mathbf v_1\cdot\mathbf v_1}\mathbf v_1\), and so on. Least squares: solve the normal equations \(A^TA\hat{\mathbf x}=A^T\mathbf b\). Inner product spaces: \(\langle f,g\rangle=\int_a^bfg\,dx\) is an inner product; Cauchy–Schwarz \(|\langle\mathbf u,\mathbf v\rangle|\le\|\mathbf u\|\|\mathbf v\|\) holds.
RecipeProject: compute \(\mathbf y\cdot\mathbf u\) and \(\mathbf u\cdot\mathbf u\). Least squares: form \(A^TA\) and \(A^T\mathbf b\), then solve the small system.
Watch outGram–Schmidt divides by \(\mathbf v_i\cdot\mathbf v_i\), not by lengths (until you normalize). The least-squares solution is \(\hat{\mathbf x}\), not the projection \(A\hat{\mathbf x}\).

Worked example

\(\mathbf y=(7,6)\), \(\mathbf u=(4,2)\): \(\mathbf y\cdot\mathbf u=40\), \(\mathbf u\cdot\mathbf u=20\), so \(\operatorname{proj}=2\mathbf u=(8,4)\).
