1. Systems and row reduction

Lay §1.1–1.2 · Week 1

In plain wordsA linear system asks where lines (or planes) meet. There are only three outcomes: no solution, exactly one, or infinitely many. Write the system as an augmented matrix and clean it with row operations. They never change the solution set.
Definitions The three row operations: replace a row by itself plus a multiple of another, swap two rows, scale a row by a nonzero number. A matrix is in echelon form if all zero rows are at the bottom, each leading entry is to the right of the one above, and entries below a leading entry are 0. It is reduced (RREF) if also every leading entry is 1 and is the only nonzero entry in its column. A pivot is a leading entry; a pivot column holds one. Variables of pivot columns are basic, the others free.
Existence and uniqueness theoremA system is consistent iff the echelon form has no row \([0\ \cdots\ 0\ |\ b]\) with \(b\neq0\). If it is consistent, the solution is unique iff there are no free variables.
Recipe: row reduction 1. Take the leftmost nonzero column: this is a pivot column. Swap so the top entry is nonzero. 2. Use replacements to make all entries below that pivot 0. 3. Ignore that row and repeat on what is left. Now you have echelon form. 4. For RREF: from the rightmost pivot upward, scale the pivot to 1 and clear above it. 5. Read off: basic variables in terms of the free ones.
Watch out A row \([0\ 0\ 0\ |\ 5]\) means no solution, while \([0\ 0\ 0\ |\ 0]\) is harmless. Free variables come from columns of the coefficient part only, never from the \(|\) column. Do arithmetic one operation at a time, and write each operation next to its row.

Worked example

Solve \(x_1-2x_2+x_3=0,\ \ 2x_2-8x_3=8,\ \ -4x_1+5x_2+9x_3=-9\).

\[\left[\begin{array}{ccc|c}1&-2&1&0\\0&2&-8&8\\-4&5&9&-9\end{array}\right]\xrightarrow{R_3+4R_1}\left[\begin{array}{ccc|c}1&-2&1&0\\0&2&-8&8\\0&-3&13&-9\end{array}\right]\xrightarrow{\frac12R_2,\ R_3+3R_2}\left[\begin{array}{ccc|c}1&-2&1&0\\0&1&-4&4\\0&0&1&3\end{array}\right]\]

Back-substitute: \(x_3=3\), \(x_2=4+4\cdot3=16\), \(x_1=2\cdot16-3=29\). Unique solution \((29,16,3)\): three pivots, no free variable.

2. Vectors, span and Ax = b

Lay §1.3–1.4 · Week 2

In plain wordsA vector is a list of numbers (an arrow in \(\mathbb R^n\)). A linear combination mixes vectors with weights. The span is everything you can reach that way. The matrix equation \(A\mathbf x=\mathbf b\) is the same question in disguise: is \(\mathbf b\) a combination of the columns of \(A\), and with which weights?
Definitions \(\mathbf y=c_1\mathbf v_1+\cdots+c_p\mathbf v_p\) is a linear combination. \(\operatorname{Span}\{\mathbf v_1,\dots,\mathbf v_p\}\) is the set of all of them. For \(A=[\mathbf a_1\ \cdots\ \mathbf a_n]\) (\(m\times n\)) and \(\mathbf x\in\mathbb R^n\): \(A\mathbf x=x_1\mathbf a_1+\cdots+x_n\mathbf a_n\).
Theorem (§1.4)For an \(m\times n\) matrix \(A\) these are equivalent: (a) \(A\mathbf x=\mathbf b\) has a solution for every \(\mathbf b\) in \(\mathbb R^m\); (b) every \(\mathbf b\) is a combination of the columns; (c) the columns span \(\mathbb R^m\); (d) \(A\) has a pivot in every row.
Recipe: is b in Span{a₁,…,aₙ}? 1. Form the augmented matrix \([\mathbf a_1\ \cdots\ \mathbf a_n\ |\ \mathbf b]\). 2. Row reduce to echelon form. 3. Consistent means yes, and the solution is the list of weights. A row \([0\cdots0\,|\,b\neq0]\) means no.
Watch out \(A\mathbf x\) exists only if the number of columns of \(A\) equals the number of entries of \(\mathbf x\). The condition is a pivot in every row, not every column. \(\operatorname{Span}\{\mathbf v\}\) for \(\mathbf v\ne\mathbf 0\) is a line through the origin; \(\mathbf 0\) is always in a span.

Worked example

Is \(\mathbf b=(7,4,-3)\) in \(\operatorname{Span}\{\mathbf a_1,\mathbf a_2\}\), with \(\mathbf a_1=(1,-2,-5)\), \(\mathbf a_2=(2,5,6)\)? Row reduce \(\left[\begin{smallmatrix}1&2&7\\-2&5&4\\-5&6&-3\end{smallmatrix}\right]\to\left[\begin{smallmatrix}1&2&7\\0&1&2\\0&0&0\end{smallmatrix}\right]\). Consistent, with \(x_2=2\), \(x_1=3\). So \(\mathbf b=3\mathbf a_1+2\mathbf a_2\): yes.
